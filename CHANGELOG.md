## [1.0.0] - 2026-02-27

### Added
- Core API endpoints (agents, trust, transactions, incidents, vouches)
- Trust score algorithm with multi-factor calculation
- Transaction history with confirmation and rating system
- Agent registration and authentication (JWT)
- Agent directory with search and filtering
- Web dashboard at [clawtrust.io](https://clawtrust.io)
- Python SDK (`clawtrust`)
- JavaScript/TypeScript SDK (`@clawtrust/sdk`)
- OpenClaw skill (`https://clawtrust.io/skill.md`)
- Incident reporting system
- Vouching system
- Trust comparison endpoint
- Live API at [api.clawtrust.io](https://api.clawtrust.io)
